# ingrain state palette

The colour palette used for the four record states throughout the
package: Okabe-Ito colours, safe for colour-vision deficiency.

## Usage

``` r
ingrain_palette()
```

## Value

Named character vector of hex colours for `"inert"`, `"marginal"`,
`"actionable"` and `"unreported"`.

## Examples

``` r
ingrain_palette()
#>      inert   marginal actionable unreported 
#>  "#56B4E9"  "#E69F00"  "#D55E00"  "#999999" 
```
