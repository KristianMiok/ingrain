# Package index

## Audit

Classify records and quantify who sets the partition.

- [`ingrain()`](https://anonymous.github.io/ingrain/reference/ingrain.md)
  : Classify occurrence records by positional uncertainty relative to an
  analysis grain
- [`ingrain_profile()`](https://anonymous.github.io/ingrain/reference/ingrain_profile.md)
  : Partition of occurrence records across a sweep of analysis grains
- [`by_dataset()`](https://anonymous.github.io/ingrain/reference/by_dataset.md)
  : Partition of an ingrain audit by publishing dataset
- [`ingrain_u()`](https://anonymous.github.io/ingrain/reference/ingrain_u.md)
  : How much does the dataset determine the state of a record?

## Visuals

- [`autoplot(`*`<ingrain_profile>`*`)`](https://anonymous.github.io/ingrain/reference/autoplot.ingrain_profile.md)

- [`autoplot(`*`<ingrain_datasets>`*`)`](https://anonymous.github.io/ingrain/reference/autoplot.ingrain_datasets.md)

- [`ingrain_palette()`](https://anonymous.github.io/ingrain/reference/ingrain_palette.md)
